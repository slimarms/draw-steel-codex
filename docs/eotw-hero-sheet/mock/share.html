What is different for EotW, and why

  • Read-only by design. The sheet only has the actions the rules allow: equip or unequip treasure, change appearance, and edit in the builder before the first win. Nothing can edit stamina or other numbers, so EotW's "enforce everything" holds.
  • One sheet everywhere. The Guild, the town strip and the in-game hero card all open this sheet, and teammates' heroes open read-only. The other ways into the old editable sheet (the C key, the token menu, search, chat commands) would point here.
  • It looks like EotW. The hero card, enlarged, anchors the sheet with the same stamina bar, recoveries ring, resource and surge icons as the HUD card, so players learn it once. Panels are frosted glass over where you are: the Hero's Guild in town, the battle map in an encounter.
  • Everything on one screen. No tabs: abilities and features sit side by side, and the left column never scrolls. Hovering shows the same ability card the action bar uses; clicking pins it.
  • Laid out the way you use it. Characteristics sit with skills, grouped by skill group, because a test is a characteristic plus a skill. Size, speed, disengage, stability and potency sit beside them.
  • Abilities follow the feature tags. Only real abilities show, plus the standard actions and free strikes every hero has, which helps newer players. Features the book writes as prose stay in Features.
  • Kit, or what the class uses instead. Prayer and ward for a Conduit, enchantment and ward for an Elementalist, and so on. A Tactician's two kits read as one kit, with the damage bonus choice made in town.
  • Treasure by type, with an equip prompt. Leveled treasure (with the carry-three count), trinkets and consumables. Won treasure currently arrives unequipped and does nothing until it is equipped, so the sheet flags it.
  • Progress on the card. Level, the bar to the next level (XP on hover) and Victories.
  • Safe to open mid-encounter. The sheet sits over the map. If a trigger, save or roll is waiting on you, the Close button turns gold and says so; EotW prompts wait rather than time out, so nothing is lost.

Open questions

  • Progression. Is levelling done with XP (victories become XP at a respite, 16 XP per level), or something else in EotW? Where does a level-up happen?
  • Moving items. Can players move items between their own heroes, share them within a party, or trade with other players? Today Give To, Set Quantity and Duplicate can inflate won treasure.
  • Carrying three leveled treasures. Hard cap, allow it with a warning, or automate the respite Presence test?
  • Edit in Builder. Your doc says before a hero's first encounter; the code allows it until the first victory, so a hero who lost stays rebuildable. Which do you want?
  • Teammates' sheets. OK to open them read-only during an encounter as well as in town?
  • Closing the other routes. Pointing the C key, token menu, search and chat commands at this sheet touches core code. OK to do?
  • Noticed along the way. The AI's "Waiting for..." banner hides whenever any panel window is open, including the character panel the HUD card opens. Intended?
  • Also noticed. In EotW every hero's character panel is view-only, which also blocks play actions such as the Summoner's Sacrifice Minions and ending an Elementalist's persistent ability.
